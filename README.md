# Rocket Boost

A 3D low-poly arcade game made with Unity 6. Fly your rocket through obstacles and land on the finish platform across 3 levels.

**Play it in your browser:** https://islander-07.itch.io/rocket-boost

## Controls
- Thrust key: boost
- Left/Right keys: rotate

## Built with
- Unity 6 (6000.0.41f1)
- C#, Cinemachine, particle effects
